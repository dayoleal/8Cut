# 8-Cut 🎨

**8-Cut** is a digital creative platform designed to encourage fanzine production. The application allows users to explore their daily creativity through collage tools, image editing, and illustrations, to produce and export a classic eight-page magazine format.

## About the Project

This project emerged from researches about the materialization of creative ideation. After an intense phase of aesthetic investigation and reference mapping, **ZineZine** was conceived as a tool that connects the visual allure of analog collages with digital assets.

### Features
* **Collage Editor:** A canvas-based interface for free manipulation of elements.
* **Illustration Tools:** Integrated support for manual drawing and handwriting via Apple Pencil.
* **Image Editing:** Application of filters and technical adjustments for a xerox-like aesthetic.
* **Print-Ready Export:** Generates files specifically configured for the 8-page zine layout (standard fold).

## Technologies & Frameworks
* **PencilKit:** Used to implement drawing tools, pens, and brushes.
* **PaperKit:** Utilized for managing object manipulation on the canvas.
* **Core Image:** The framework responsible for image processing and dynamic filter application.
